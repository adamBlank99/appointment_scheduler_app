# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately with GitHub's **Report a vulnerability** option on the repository's Security tab. Include the affected route or component, reproduction steps, and impact, but do not include real appointment data, passwords, access tokens, or service credentials.

Do not open a public issue containing exploit details or private user information. If private vulnerability reporting is unavailable, open a minimal issue asking the owner for a private contact method without disclosing the vulnerability.

This portfolio project has no bug-bounty program and does not authorize destructive testing, denial-of-service testing, automated account creation, access to another person's data, or testing against infrastructure outside this repository.

## Supported version

Only the current production deployment from the `main` branch is supported. Dependencies are monitored through Dependabot and the continuous-integration audit.
